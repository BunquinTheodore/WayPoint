# Waypoint mascot

Selected visual direction: a minimal black cat inspired by the three cat references provided on October 9, 2026.

Master asset: `waypoint-cat.png`, a transparent RGBA PNG generated with the built-in image generator.

Keep the solid black silhouette, oversized white eyes, tall ears, small white nose, short whiskers, and curled tail. Use no scarf, badge, clothing, gradients, or colored accents. Display on a light background so the silhouette remains visible.

The earlier pigeon and shaded cat in `output/mascot/` are previous concepts. The master asset is prepared for use; no application screens have been changed by this mascot selection.

Generation prompt: `output/mascot/minimal-cat-prompt.txt` at the project root.
